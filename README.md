## 📌 Featured projects

### 🎮 [Game Library Tracker](https://github.com/erminhadzic4/game-library-tracker)

A full-stack web app for tracking your video game library.

- 🔐 **Spring Boot REST API** with **JWT authentication** and **PostgreSQL**
- 🔎 Live game search and discovery lists powered by the **RAWG API**, with caching (Caffeine)
- 📚 Personal library with status (Playing / Backlog / Completed), ratings 1–10, notes and stats
- ⚛️ Responsive dark UI built with **React 19 + TypeScript + Vite**
- 🧪 **92 backend tests** (JUnit 5, Mockito, MockMvc) and **CI with GitHub Actions**
- 📖 OpenAPI / Swagger documentation and consistent RFC 9457 error responses

`Java 17` `Spring Boot` `PostgreSQL` `JWT` `React` `TypeScript` `Maven` `GitHub Actions`

[![Repo](https://img.shields.io/badge/View%20repository-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/erminhadzic4/game-library-tracker)
